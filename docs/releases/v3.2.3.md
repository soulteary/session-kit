# session-kit v3.2.3

This patch selects `redis-kit` v1.8.3 for the optional Redis backend and
refreshes the Fiber adapter's indirect dependencies. It contains no library
source changes.

`go.sum` also records `golang.org/x/tools` v0.52.0 (previously v0.51.0), used
by transitive dependency tests.

Go 1.27.4, Fiber v3.7.0, go-redis v9.23.0, and the
`github.com/soulteary/session-kit/v3` module path are unchanged. The root
package continues to use only the standard library.

## Upgrade and rollback

```sh
go get github.com/soulteary/session-kit/v3@v3.2.3
```

No session record migration or reauthentication is required when upgrading
from v3.2.2. Existing namespace, lifetime, revocation, and storage settings
remain applicable. For earlier releases, follow the
[v3.2.2 compatibility notes](v3.2.2.md) and
[v3.2.0 revocation migration](v3.2.0.md).

To roll back, restore the application's previous `go.mod` and `go.sum`, then
rebuild. Downgrading session-kit alone can leave newer transitive dependencies
selected by another requirement in the application.
