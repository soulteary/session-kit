# session-kit v3.2.4

This patch selects `go-redis/v9` v9.24.0 and `redis-kit` v1.8.4 for the
optional Redis backend. The module requires Go 1.27.4.

| Module | Previous | Updated |
| --- | --- | --- |
| `github.com/redis/go-redis/v9` | v9.23.0 | v9.24.0 |
| `github.com/soulteary/redis-kit` | v1.8.3 | v1.8.4 |

## Redis client compatibility

The upstream client changes exhausted dial retries, context-deadline error
matching and enforcement of `MaxActiveConns`. Review application retry,
timeout and pool settings against the
[go-redis v9.24.0 notes](https://github.com/redis/go-redis/releases/tag/v9.24.0).

## Upgrade and rollback

```sh
go get github.com/soulteary/session-kit/v3@v3.2.4
```

Upgrading from v3.2.3 requires no session-record migration or reauthentication.
Existing namespace, lifetime, revocation and storage settings remain applicable.
For earlier releases, follow the [v3.2.2 compatibility notes](v3.2.2.md) and
the [v3.2.0 revocation migration](v3.2.0.md).

To roll back, restore the application's previous `go.mod` and `go.sum`, then
rebuild. Downgrading session-kit alone can leave newer Redis dependencies
selected by other requirements in the application.
