# session-kit v3.2.5

## Changes

- Update the indirect Fiber adapter requirement `github.com/gofiber/schema` from v1.10.0 to v1.10.2.
- Refresh CI and release-validation Actions dependencies.

The module path and public API are unchanged. The Go requirement remains 1.27.4. Fiber stays in the optional adapter.

## Upgrade and rollback

```sh
go get github.com/soulteary/session-kit/v3@v3.2.5
```

This patch introduces no application configuration or stored-data migration. Restore the application's previous `go.mod` and `go.sum` and rebuild to roll back; Go minimal version selection may retain newer dependencies selected elsewhere.

Full changes: https://github.com/soulteary/session-kit/compare/v3.2.4...v3.2.5
